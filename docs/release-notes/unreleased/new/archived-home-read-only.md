- **An archived home is read only.** Its pages still open, with the banner **Archived home: read only**, but nothing in it can be changed, by any member, from the screens, the API, Home Assistant or the mobile app, until an owner brings it back from that banner or from the page of the home. It can still be exported or deleted, and you can still leave it or take someone's access away. The mobile app already worked this way; nothing is deleted ([ADR 0089](../../../adr/0089-an-archived-home-is-read-only.md)).
