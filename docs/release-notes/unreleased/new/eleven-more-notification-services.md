- **Eleven more notification services.** With Apprise 2.2.0, the **Notifications** screen offers CM.com, FireHydrant, Groundmail, Gupshup, Infobip, KakaoTalk, Kaleyra, SMSTunnel, Telesign, Whapi.Cloud and xMatters, each with a fixed form like the other services. Nostr is not offered: it publishes public notes over WebSocket, not over HTTP(S) or SMTP, so it does not fit the criteria ([Notifications](../../../guides/notifications.md), [ADR 0064](../../../adr/0064-every-apprise-service-with-a-fixed-format.md)).
