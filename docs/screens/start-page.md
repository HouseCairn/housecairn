# Start page

The root address of the instance, `/`. What it shows depends on who opens it:

- **Signed out**: the name of the application and **Sign in**.
- **Signed in with one home**: it opens the [Today](today.md) of that home. The
  logo, **Today** in the navigation, the address an installed application starts
  on and the page you reach after signing in all lead here, so the day always
  starts on Today.
- **Signed in with several homes**: the [Today](today.md) of the
  [current home](my-home.md#the-current-home), or [Today in several homes](my-home.md)
  when you chose **All homes** (and before you chose a home).
- **Signed in with no home to open**: the welcome page, with **Add a home** and **My
  homes**, and a card **Guide** whose **Open the guide** leads to the [guide](guide.md), to try
  the application on an example home. The example home does not count as a home to open
  here: with it alone, the welcome page stays.
